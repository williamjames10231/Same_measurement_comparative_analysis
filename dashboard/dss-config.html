Composite weights · sentiment classifications admin-set

Drives the responders' Overall allocation priority queue. Defaults are equal (33% / 33% / 33% after normalisation — no emphasis). Every criterion is a benefit. Changes re-rank the queue instantly and persist on this device.

Channel weight profiles admin-set

Each profile drives one responder sublist — consultation focus, sensitive information dissemination, expertise, materials and supplies. Defaults are equal (34 / 33 / 33) on every channel — no emphasis. Adjust only when a stakeholder briefing explicitly requires it; responders see the ranked lists plus a read-only disclosure of these weights.
