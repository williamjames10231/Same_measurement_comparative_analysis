Resource Allocation (TOPSIS)

Built on topic modelling (what people talk about) and sentiment classification (how they talk about it). TOPSIS ranks the six discovered topics so responders can allocate resources — which topics to focus on in consultations, where sensitive information dissemination, expertise and materials are needed most. By default every list uses equal weights (33% / 33% / 33% after normalisation — no emphasis); a human confirms each allocation, and stakeholders can build their own free sublist below.

Channel sublists · where each resource goes first

Each allocation channel re-weights the same sentiment criteria to answer a different resource question — consultation focus, sensitive information dissemination, expertise, materials and supplies. Defaults are equal weights (34 / 33 / 33) across every channel — no emphasis unless the administrator explicitly sets one in DSS Configuration. The chips on every card disclose the weights (responders see them read-only).

Free sublist · your own prioritisation

Set your own composite weights for the three sentiment criteria — the TOPSIS rank recomputes live and is kept on this device. Defaults are equal (33% / 33% / 33%). This is the stakeholder-defined list: it does not change what responders or the administrator see elsewhere.
